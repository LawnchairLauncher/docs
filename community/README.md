# Roadmap and future features

## Vision

Lawnchair aims to:

* Match the core Pixel Launcher experience.
* Offer deep, meaningful customization.
* Provide a reliable foundation.

### Development status

Lawnchair is an open-source project driven entirely by volunteers. Contributors work on the project in their free time, alongside jobs, school, and other personal commitments.

Development pace varies, but Lawnchair remains under active development. Follow the [GitHub commit history](https://github.com/LawnchairLauncher/lawnchair) or install a Nightly build to see recent changes.

### Release policy (ETAs)

We do not publish estimated release dates. The project is volunteer-run, so deadlines are hard to predict and can put unnecessary pressure on contributors. Releases are published when they are ready.

### Future goals and roadmap

The roadmap depends on contributor availability, so we do not set timelines. Current goals include:

* Port all Lawnchair Legacy features.
* Add highly requested community features.
* Simplify the Lawnchair user experience.

For more detailed planning, you can review our project's roadmap and open issues on GitHub.
